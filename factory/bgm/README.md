# 영상 BGM — 오즈백 뮤직 연주곡

여기 있는 mp3는 **오즈백이 직접 만든 곡**입니다. 저작권이 우리에게 있어
유튜브·인스타·페북 어디에 올려도 저작권 문제가 없습니다.

| 앞머리 | 앨범 | 분위기 | 쓰이는 카테고리 |
|---|---|---|---|
| `rain-` | BGM-01 「비 오는 카페」 | 차분·잔잔 | 경제 · 사회 · 문화·연예 |
| `sunny-` | BGM-02 「볕 드는 날」 | 밝음·산뜻 | IT·테크 · 트렌드 · 스포츠 |

- 원본(무손실 wav)은 `02_뮤직/01_앨범/` 에 있습니다. 여기 있는 건 **영상용 사본**입니다.
  (모노 64kbps · 최대 185초 · 음량 -14 LUFS로 통일)
- 글마다 곡이 하나로 고정 배정됩니다 — 같은 글은 늘 같은 곡, 글이 다르면 다른 곡.
- 곡을 더하거나 빼려면 이 폴더에 mp3를 넣고 빼기만 하면 됩니다. 코드는 안 고쳐도 됩니다.
- 이 폴더가 통째로 없으면 예전 합성음으로 자동으로 넘어갑니다 (영상 제작은 안 멈춤).

## 다시 만드는 법
```
ffmpeg -i 원본.wav -t 185 -af "loudnorm=I=-14:TP=-1.5:LRA=11" \
       -ac 1 -ar 44100 -c:a libmp3lame -b:a 64k bgm/rain-곡이름.mp3
```
음량(-14 LUFS)은 예전 합성 BGM과 같은 크기로 맞춘 값입니다. 바꾸면 나레이션과의 균형이 깨집니다.
