# 서버 없이 돌리는 시험

외장하드에서는 `next dev` 가 Turbopack 캐시가 깨져 두 번째부터 죽는다.
그래서 순수 함수는 서버를 안 띄우고 그대로 시험한다.

**한 번에 다 돌리기**

```
cd homepage
for f in ./scripts/시험/*-시험.mjs; do
  OB_ROOT="$PWD" node --experimental-strip-types --import ./scripts/시험/별칭.mjs "$f" || break
done
node content-factory/casebook-검사.mjs
```

| 파일 | 무엇을 지키나 |
|---|---|
| `별칭.mjs` | 다음(Next)만 아는 `@/` 별칭과 `.ts` 확장자 생략을 node 에 알려 주는 갈고리 (시험 아님) |
| `챙길것-시험.mjs` | 「챙길 것」이 «누구에게 무엇을 보여줄지» 정하는 규칙 |
| `주소지킴이-시험.mjs` | 스크랩 정리기가 우리 서버로 열어 주는 주소의 안팎 판정 (SSRF) |
| `사진도구-시험.mjs` | 사진 줄이기·증명사진·글자수 세기가 쓰는 계산 |
| `게시판-시험.mjs` | 도구 글이 «어느 도구 밑»에 붙는지 (힌트가 겹치면 조용히 틀린다) |

케이스북 데이터 자체는 따로 검사한다:

```
node content-factory/casebook-검사.mjs
```

## 왜 이렇게까지 하나

여기서 잡는 것은 전부 **조용히 틀리는** 종류다. 화면은 멀쩡히 뜨고 오류도 안 난다.

- 게시판 힌트가 겹쳐 새 글 8편이 통째로 엉뚱한 도구 밑으로 갔다 (2026-08-26)
- 주소 검사가 «글자»만 봐서, 사설 IP를 가리키는 공개 도메인이 통과했다 (2026-08-26)
- 「확인 안 된 케이스북」이 도구에 새어 나갈 뻔했다

눈으로 보고 넘어가면 다음 사람이 같은 자리에서 또 넘어간다.
